Portfolio Website

เว็บไซต์ Portfolio ส่วนบุคคลที่พัฒนาขึ้นเพื่อรวบรวม และนำเสนอข้อมูลส่วนตัว ประวัติการศึกษา ผลงาน กิจกรรม และทักษะต่าง ๆ โดยใช้ HTML ในการกำหนดโครงสร้างของเว็บไซต์ และ CSS ในการออกแบบรูปแบบการแสดงผล เพื่อให้เนื้อหามีความเป็นระเบียบและสื่อสารข้อมูลได้อย่างชัดเจน

ทำไมต้องสร้าง Portfolio Website

ผมต้องการเรียนรู้การพัฒนาเว็บไซต์ด้วยตนเอง จึงเริ่มต้นจากการศึกษาพื้นฐาน HTML และ CSS แล้วนำความรู้ที่ได้มาประยุกต์ใช้ในการสร้างเว็บไซต์ Portfolio ของตนเอง โดยมุ่งเน้นการออกแบบหน้าตาเว็บไซต์ การจัดวางองค์ประกอบ และการนำเสนอข้อมูลให้เหมาะสม สวยงาน และมีความทันสมัย

สิ่งที่ได้รับจากการสร้าง My Portfolio Website

ในระหว่างการพัฒนา ผมได้ฝึกแก้ไขปัญหาที่เกิดจากการกำหนด CSS เช่น การจัดตำแหน่งองค์ประกอบ การปรับขนาดและระยะห่างของกล่อง รวมถึงการจัดวางเนื้อหาให้สอดคล้องกัน นอกจากนี้ยังได้ศึกษาเทคนิคการใช้ Flexbox, Grid และ Responsive Design เพื่อให้เว็บไซต์ปรับรูปแบบการแสดงผล ให้เหมาะสมกับขนาดหน้าจอที่แตกต่างกัน

จากการทำเว็บไซต์นี้ ผมได้เรียนรู้กระบวนการพัฒนาเว็บไซต์ ตั้งแต่การกำหนดโครงสร้าง HTML การตกแต่งด้วย CSS ไปจนถึงการทดสอบและปรับปรุงการแสดงผล อีกทั้งยังได้ฝึกทักษะการคิดอย่างเป็นระบบ การแก้ปัญหา และการเรียนรู้เทคโนโลยีด้วยตนเอง
